# Electrical-Layout-Design-of-A-Four-Storied-Residential-Building-
AutoCAD-based electrical design for a four-storey, eight-unit residential building, covering lighting and power layouts, load calculations, cable and breaker sizing, distribution diagrams, generator-backed emergency supply, communication networks, and lightning protection. Developed by Group 4(C1) for EEE 4418 at IUT.
